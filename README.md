# Alex Gonzalez / Engineering Portfolio — Biography & navigation update (v8)

This revision builds on the working right-shifted glowing scroll-circle website.

- Header wordmark (`Alex Gonzalez / Engineering`) is now plain display text instead of a clickable, animated menu item, on every page.

## Installation

**Update ZIP:** Extract and upload `index.html`, `about.html`, `contact.html`, `future.html`, `project.html`, and `style.css` to the repository root, replacing the existing files. No image/assets folder update is required.

**Complete ZIP:** An entire website backup, including assets and scripts.

After GitHub Pages deploys, hard-refresh with Ctrl+Shift+R. HTML pages use `style.css?v=biography-v8` to avoid stale CSS.
